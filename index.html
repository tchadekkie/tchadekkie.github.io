케어톡

몸을 움직이기 어려운 병상 환자가 한 번의 ‘잡기’로 말을 만들 수 있도록 돕는 의사소통 앱입니다. 어휘는 서울시장애인의사소통권리증진센터 「입원 환자용 AAC 도구」의 다섯 가지 의도 — 필요해요 · 궁금해요 · 도와주세요 · 불편해요 · 통증이 있어요 — 를 반영했습니다. 사용할 방식을 골라 주세요.

※ 태블릿·폰 모드는 화면 진입 후 상단 🔗 연결에서 연결 방식을 고릅니다. 같은 브라우저의 두 탭은 같은 기기로 바로 연결되고, 서로 다른 두 기기는 같은 WiFi에서 WiFi 직접 연결(서버 없이 코드/QR 교환)로 묶을 수 있습니다. 블루투스는 케어톡 BLE 서비스를 가진 기기에 연결되며, 폰↔폰 직결은 안드로이드 앱(Capacitor BLE)으로 감싸면 됩니다. 시리얼(USB)은 PC 크롬에서 아두이노 등 USB 시리얼 장치(115200bps)를 ‘잡기’ 버튼으로 연결합니다.

엑셀로 메뉴 추가

엑셀 파일의 텍스트 항목과 삽입된 아이콘 그림을 읽어 스캔 메뉴로 추가합니다. 추가된 메뉴는 첫 화면 목록 끝에 나타나고, 이 기기에 저장됩니다.

엑셀 작성 방법 — 1행은 제목 줄로 두고 아래 열 이름을 사용하세요.
· 카테고리 : 묶음 이름(비우면 시트 이름 사용)
· 텍스트 : 버튼에 보일 짧은 말 (필수)
· 문장 : 실제로 말할 완성 문장(비우면 텍스트 그대로)
· 이모지 : 아이콘 대신 쓸 이모지(선택)
· 아이콘 그림 : 해당 행 위에 삽입(삽입 ▸ 그림 ▸ 셀 위)하면 자동으로 그 항목의 아이콘이 됩니다.

아직 연결되지 않았어요
같은 브라우저의 두 탭/창에서 즉시 연결됩니다. 한 기기로 시험하거나, 같은 기기에서 태블릿·폰 모드를 함께 띄울 때 쓰세요.
같은 WiFi·핫스팟에 있는 서로 다른 두 기기를 인터넷 서버 없이 직접 연결합니다. 한 기기는 초대, 다른 기기는 참여를 골라 코드를 한 번씩 주고받으면 됩니다.
1초대 코드를 만들어 상대 기기에 보여주세요
2상대가 만든 응답 코드를 받아 붙여넣고 연결을 끝내세요
1상대의 초대 코드를 붙여넣으세요
2만들어진 응답 코드를 상대 기기에 보여주세요
블루투스(BLE)는 케어톡 BLE 서비스(예: UNO R4 잡기 컨트롤러 CareTalk-R4)를 제공하는 기기에 연결합니다. 브라우저는 BLE에서 중앙(연결하는 쪽)만 될 수 있어, 폰↔폰 직접 페어링은 케어톡을 안드로이드 앱(Capacitor BLE 주변기기)으로 감싸야 가능합니다. 폰·태블릿 두 대만 있다면 WiFi를 권합니다.
USB로 연결된 아두이노 등 시리얼 장치(115200bps)를 ‘잡기’ 컨트롤러로 사용합니다. 장치는 줄바꿈으로 구분된 JSON — {"k":"catch"}(잡기), {"k":"sos","on":true}(비상), {"k":"hello"}(연결 유지) — 를 보내면 됩니다.
Web Serial은 PC 크롬/엣지에서만 지원됩니다(안드로이드 크롬 미지원 — 안드로이드는 WiFi/블루투스를 이용하세요). 또한 파일은 https 또는 localhost에서 열어야 포트 선택 창이 뜹니다(file:// 열기도 대부분 동작).
